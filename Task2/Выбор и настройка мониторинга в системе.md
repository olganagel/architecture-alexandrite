# 1. Мотивация
Внедрение мониторинга повышает наблюдаемость системы, что дает: 
- оперативное обнаружение проблем для понимания, что чинить
- отслеживание поведения пользователей для генерации новых идей по улучшению системы
- обеспечение безопасности системы в виде отслеживания необычного поведения и атак

# 2. Выбор подхода к мониторингу

## USE 
Для мониторинга бекэнд-приложений

## RED 
Для мониторинга инфраструктуры

# 3. Какие метрики и в каких частях системы отслеживать

## Redis
- утилизация памяти used_memory 
- количество найденных значений в кеше cache_hits
- количество промахов кеша cache_misses 

## MES 
- количество ошибок errors_total 
- количество таймаутов timeouts_total
- количество запросов requests_total

## RabbitMQ
- количество ожидающих сообщений waiting_messages
- количество обрабатывающихся сообщений processing_messages
- количество сообщений, которые не смогли обработать по ошибке failing_messages
